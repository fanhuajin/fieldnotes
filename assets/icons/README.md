Brand adaptations in ../logo.svg and ../favicon.svg retain the apps paths, adding a white rounded background, scaling and SoftShelf's blue colors. ../icons.css only renders the category SVGs at the native group-icon size and color; Homer layout, cards, welcome message and interaction code are unchanged. Software product logos are not replaced.
